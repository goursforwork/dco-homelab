AWS DCO Home Lab

Project Overview

This repository documents my self-directed practical learning in server hardware, data-center operations, Linux, networking, troubleshooting, and AWS infrastructure concepts.

The project is designed as a hands-on home lab to build practical skills relevant to Data Center Operations (DCO), Data Center Technician, Infrastructure Technician, and cloud infrastructure support roles.

Note: This is an independent home-lab and learning project. It does not represent production AWS work, employment at AWS, or access to Amazon internal systems.

Disclaimer

All exercises documented here are performed in personal lab environments, virtual machines, simulations, publicly available cloud services, or educational environments.

Nothing in this repository should be interpreted as experience working on Amazon/AWS production infrastructure or accessing proprietary AWS systems.
