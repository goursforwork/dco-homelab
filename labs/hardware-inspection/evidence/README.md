# Evidence Folder

Put only **redacted** photographs/screenshots here. Example evidence to collect:

- `01-firmware-summary-redacted.png` — firmware version and capacity shown in setup screen
- `02-windows-system-info-redacted.png` — BIOS Mode, installed memory, and OS details
- `03-os-inventory-redacted.png` — output of non-sensitive hardware inventory commands

Avoid uploading screenshots containing usernames, real hostnames, serial numbers, asset tags, IP/MAC addresses, network names, BitLocker recovery keys, QR codes, or identifying desktop notifications. Blur/redact **before committing**. You can also use a written observation instead of screenshots.
